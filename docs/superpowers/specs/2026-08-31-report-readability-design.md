# Report 分类与可读性改进设计

## 目标

让周报清楚地区分项目动态和新模型，并让读者在模型条目中直接看到最重要的判断内容。

## 范围

- ModelScope 数据只进入“新模型”章节。
- GitHub watch repos（包括 LangChain、AgentScope、vLLM 等）只进入“项目动态”章节。
- GitHub 搜索结果继续作为独立的潜在新项目章节。
- 删除每条 Release 的发布时间行。
- 删除模型研判中的独立“学习价值”和重复“一句话”包装，只保留一段紧凑摘要。
- 报告生成时间和模型创建时间统一显示为 `YYYY-MM-DD HH:MM`。
- 不重写已有历史报告。

## 实现

`scan.py:build_report` 负责章节和条目格式；`fetch_ms_new_models` 保持现有结构化字段供模型研判使用。Release 提示词要求输出一段以变化和关注理由为主的摘要，模型提示词要求优先描述模型用途/能力，再说明部署或关注理由。日期格式化使用一个小型本地辅助函数，解析带时区和无时区的 ISO 日期。

## 验收

1. 新生成报告中，LangChain/AgentScope 不出现在新模型章节。
2. 新模型章节只消费 ModelScope 返回的模型。
3. 报告不再包含 `学习价值`、独立 `一句话` 或 `发布时间:` 行。
4. 报告生成时间、模型创建时间不包含 `T` 或 `Z`。
5. 模拟 Release、项目和模型数据时，三章节内容和摘要均完整可读。
